# One Line, One Minute: The Vending Machine Pickup Line — entry

A program/v1 entry for the make.fun vending-machine pickup
line bounty. `main.py` writes one pickup line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The line:

> You check my prices every day at six. One day you'll press B4, and I'll be ready: cold, exact change, no judgement.

A vending machine's whole romantic strategy is the long
game: it has memorised your routine, it keeps your drink at
the perfect temperature, and it can wait forever. An earlier,
smoother draft was rejected for wasting the machine's one
real asset -- months of watching you walk past. See
`CANDIDATES.md` for the full draft list.
